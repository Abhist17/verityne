# Departure Mono

`DepartureMono-Regular.woff2` — Departure Mono by Helena Zhang, licensed
SIL Open Font License 1.1. https://departuremono.com

Self-hosted through `next/font/local` rather than a CDN so the display face is
subject to the same rule as the rest of the fonts here: the browser makes no
third-party request at runtime.

It is the *display* face only — page titles, the hero, micro-labels. Numbers
and code stay in JetBrains Mono, which has real tabular figures; a bitmap face
at 12px in a data table is a costume, not a typeface choice.
